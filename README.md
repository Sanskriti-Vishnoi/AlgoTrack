# AlgoTrack: DSA Progress Tracker

An Android app to track DSA practice topic by topic, with your own notes and logic tags.

## Features
- Sign up / log in; your progress is saved to your account
- Built-in problem sheet organised by topic, with progress on a dashboard
- Add your own topics and problems
- Add logic tags and notes to each problem
- Search and filter by difficulty (Easy / Medium / Hard)
- Real-time cloud sync with Firebase Firestore

## Tech stack
Kotlin, Jetpack Compose, MVVM, Kotlin Coroutines, Firebase Authentication, Firestore
